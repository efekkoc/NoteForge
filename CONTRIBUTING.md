# Contributing to NoteForge AI ⚡

Thank you for your interest in contributing to **NoteForge AI**!

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/NoteForge.git
   cd NoteForge
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make Your Changes** and verify:
   ```bash
   npm run lint
   npm run build
   ```
5. **Commit Your Changes**:
   ```bash
   git commit -m "feat: add amazing feature"
   ```
6. **Push to Your Fork** and open a **Pull Request** targeting the `main` branch.

## Code Style & Guidelines
- Use TypeScript with strict types where appropriate.
- Follow Tailwind CSS utility patterns matching the AquaForge theme (cyan/teal/midnight slate).
- Ensure zero lint warnings (`npm run lint`).
