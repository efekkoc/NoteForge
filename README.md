## 🌟 Overview

**NoteForge AI** is an intelligent lecture and academic study assistant designed to bridge physical classroom learning with an autonomous digital knowledge hub. 

Snap chalkboard formulas, handwritten notebook pages, or lecture slides with your camera. NoteForge leverages **Gemini 2.5 Flash Multimodal Vision** to transcribe equations into formatted $LaTeX$, extract high-yield executive summaries, predict likely exam questions, and organize everything into dedicated course vaults.

---

## 🎯 Features

- ⚡ **AquaForge-Inspired Design System:** Deep midnight dark mode (`#070b14`), electric cyan/teal gradients, neon glows, and responsive cards.
- 📸 **Camera & Image Vision:** Mobile/webcam instant photo capture and drag-and-drop file processing.
- 🧠 **Multimodal OCR & Formula Extraction:** Converts handwriting, diagrams, and complex math into clean KaTeX/LaTeX Markdown.
- 📚 **Autonomous Course Vaults:** Automatically recognizes the course subject or allows custom course creation with color coding.
- 🌍 **Trilingual Localization:** 1-click switcher for **Türkçe (TR)**, **English (EN)**, and **Español (ES)**, with localized AI prompt outputs.
- ℹ️ **Interactive User Guide:** Built-in step-by-step walkthrough covering API keys, photo capture, AI analysis, and exports.
- 📄 **Developer-Friendly Exports:** 1-click Markdown (`.md`) download, clipboard copy, and side-by-side original image inspection.
